**** This app is up-and-running at https://us-chr-dashboard-v3.streamlit.app/ ****

To run this on your own device, you will need to download all files and install the libraries listed in the requirements.txt file.

In a python console, type "streamlit run US_CHR_Dashboard_v3.py"

Original data files can be found at countyhealthrankings.org, however, the data is provided in separate csv 
for each year, and column titles change and columns come and go from year to year.
